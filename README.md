# JustinYuu.github.io

Personal academic homepage of Jiashuo Yu, served at https://justinyuu.github.io/.

Plain HTML/CSS, based on [Jon Barron's template](https://github.com/jonbarron/jonbarron.github.io). No build step.

## Updating

- **News**: add a `<li>` at the top of the `News` list in `index.html`.
- **Selected Publications**: copy any `<tr>...</tr>` block, put a teaser image (~480px wide) in `images/`, and edit the text.
- **Other Publications**: add a `<li>` to the `publist`.
- **Photo**: replace `images/profile.svg` with your photo (e.g. `images/profile.jpg`) and update the two references in `index.html`.
- **CV**: put the PDF in `data/` and uncomment the CV link in the intro.
